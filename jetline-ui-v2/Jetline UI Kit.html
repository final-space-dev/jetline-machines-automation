Jetline UI

A complete, shadow-driven component system built from the courier menu aesthetic — soft elevation, generous radius, a single confident red, and absolutely no hard lines. Drop in tokens.css + the component sheets and build.

Color

One brand red, a cool neutral ramp, and restrained semantics. Tints carry most of the UI; saturated red is reserved for primary actions.
